# TETR.JS

TETR.IO 스타일의 모던 테트리스입니다. 순수 HTML / CSS / JavaScript로 만들었고, 빌드나 설치 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/hyeophap-del/test1.git
   ```
2. `index.html`을 브라우저로 엽니다.
3. **Enter** 또는 **START** 버튼을 누르면 게임이 시작됩니다.

## 조작키

| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| A | 180° 회전 |
| C / Shift | 홀드 |
| Esc / P | 일시정지 |
| R | 재시작 |
| Enter | 시작 / 계속 |

위는 기본값이며, 모든 키는 설정 창에서 바꿀 수 있습니다 (아래 [설정](#설정) 참고).

## 기능

- **7-bag 랜덤**: 7종 미노를 한 묶음으로 섞어 중복 없이 내보내고, NEXT에 5개까지 보여줍니다.
- **SRS 회전**: 표준 벽차기(킥) 테이블을 쓰고, TETR.IO식 180° 회전도 지원합니다.
- **홀드**: 미노 하나당 한 번만 쓸 수 있으며, 쓸 수 없을 때는 홀드 칸이 회색으로 표시됩니다.
- **DAS / ARR**: 키를 누르고 있으면 일정 시간 후 연속으로 이동합니다.
- **소프트 / 하드 드롭**: 소프트 드롭은 칸당 1점, 하드 드롭은 칸당 2점입니다.
- **고스트 피스**: 미노가 떨어질 위치를 반투명하게 보여줍니다.
- **락 딜레이**: 바닥에 닿은 뒤 0.5초 후 고정되며, 이동·회전으로 최대 15번까지 연장됩니다.
- **레벨**: 10줄을 지울 때마다 레벨이 오르고 낙하 속도가 빨라집니다 (최대 20).
- **보너스 점수**: T-스핀(Mini 구분), Back-to-Back, 콤보, 올 클리어.
- **통계**: 점수, 라인, 레벨, 놓은 미노 수, PPS(초당 미노 수), 경과 시간.

## 점수표

아래 점수에 현재 레벨을 곱합니다.

| 동작 | 점수 |
|---|---|
| Single / Double / Triple / Quad | 100 / 300 / 500 / 800 |
| T-Spin Mini (0 / 1 / 2줄) | 100 / 200 / 400 |
| T-Spin (0 / 1 / 2 / 3줄) | 400 / 800 / 1200 / 1600 |
| Back-to-Back (Quad, 줄을 지운 T-스핀 연속) | × 1.5 |
| 콤보 | 50 × 콤보 수 |
| 올 클리어 (1 / 2 / 3 / 4줄) | 800 / 1200 / 1800 / 2000 |

## 설정

시작 화면의 **SETTINGS** 버튼이나 오른쪽 패널의 **⚙ 키 / 핸들링 설정** 버튼으로 설정 창을 엽니다. 게임 중에 열면 자동으로 일시정지됩니다. 바꾼 값은 바로 적용되고 브라우저(localStorage)에 저장되어 다음에 열어도 유지됩니다.

### 핸들링

| 항목 | 범위 | 기본값 | 설명 |
|---|---|---|---|
| DAS | 0–333ms | 133ms | 연속 이동이 시작되기까지의 지연 |
| ARR | 0–100ms | 10ms | 연속 이동 간격 (0이면 즉시 벽까지) |
| DCD | 0–333ms | 0ms | DAS가 충전된 상태에서 회전·드롭·홀드한 직후 연속 이동을 멈추는 시간 |
| SDF | 1–40x, ∞ | 20x | 소프트 드롭 배율 (∞이면 즉시 바닥까지) |

### 조작키

- 동작마다 키를 3개까지 지정할 수 있습니다.
- 칸을 클릭하고 원하는 키를 누르면 지정됩니다. 다시 클릭하면 취소, 우클릭하면 지워집니다.
- 다른 동작에 이미 쓰인 키를 지정하면 그 동작에서 빠지고 알림이 표시됩니다.
- 키가 하나도 없는 동작은 빨간색으로 표시됩니다.
- 섹션별 **기본값** 버튼으로 되돌릴 수 있습니다. 설정 창은 Esc나 바깥 클릭으로 닫습니다.

락 딜레이, NEXT 개수 등 게임 규칙 값은 `game.js` 위쪽의 `CONFIG`에서 바꿀 수 있습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 (HOLD, 보드, NEXT, 통계, 조작키 안내) |
| `style.css` | 어두운 TETR.IO 풍 테마와 액션 텍스트 애니메이션 |
| `settings.js` | 조작키·핸들링 설정 창과 저장 (`game.js`보다 먼저 로드) |
| `game.js` | 게임 로직과 Canvas 렌더링 |
